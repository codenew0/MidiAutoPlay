# FF14 MIDI Player

FINAL FANTASY XIV の演奏機能（パフォーマー）向けに、MIDIファイルを自動でキー入力に変換して演奏するツールです。

## スクリーンショット

> メインウィンドウとオーバーレイウィンドウ

## 機能

- **MIDIファイル / フォルダの読み込み** — 単一ファイルまたはフォルダ内の全MIDIを一括登録
- **プレイリスト** — 複数曲を順番に自動再生
- **自動オクターブ調整** — 曲の音域をFF14キーボード範囲（C4〜C7）に自動フィット
- **手動オクターブシフト** — ±1オクターブ単位で手動調整可能
- **再生速度調整** — 0.1x〜2.0x のリアルタイム速度変更
- **シークバー** — クリックで任意の位置にジャンプ
- **トラックミュート** — 演奏したくないトラックをダブルクリックでミュート
- **オーバーレイウィンドウ** — ゲーム中でも操作できる常時最前面の小型コントロール
- **グローバルホットキー** — ゲームウィンドウにフォーカスがあっても操作可能

| ホットキー | 操作 |
|---|---|
| `Ctrl + Alt + P` | 再生 / 一時停止 |
| `Ctrl + Alt + S` | リセット |
| `Ctrl + →` | 次の曲 |
| `Ctrl + ←` | 前の曲 |

## キーマッピング

FF14 のパフォーマーキーボード（37鍵）に対応しています。

| MIDI音域 | キー |
|---|---|
| C3〜B3 (48〜59) | `1 2 3 4 5 6 7 8 9 0 q w` |
| C4〜B4 (60〜71) | `e r t y u i o p a s d f` |
| C5〜C6 (72〜84) | `g h j k l z x c v b n m ,` |

## 動作環境

- Python 3.10 以上
- Windows（`pynput` のキー送信はWindowsを想定）

## インストール

```bash
git clone https://github.com/yourname/FF14MidiPlay.git
cd FF14MidiPlay
pip install -r requirements.txt
```

## 使い方

```bash
# リポジトリのルートディレクトリから実行
python main.py
```

1. **ファイル選択** または **フォルダ選択** でMIDIファイルを読み込む
2. 必要に応じて「キーボード範囲に自動調整」にチェックを入れる
3. ▶ PLAY ボタン（または `Ctrl+Alt+P`）で演奏開始
4. FF14のキャラクターがパフォーマーモードになっていることを確認してください

> **注意**: 再生中はキーボード入力をプログラムが制御します。停止する場合は `Ctrl+Alt+S` またはオーバーレイの ⏹ ボタンを使用してください。
